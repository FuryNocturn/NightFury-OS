# Política de seguridad

## Versiones soportadas

Solo la última versión publicada recibe correcciones.

## Cómo avisar de una vulnerabilidad

**No abras un issue público.** Usa el aviso privado de GitHub: pestaña **Security** del repositorio →
**Report a vulnerability** (Private vulnerability reporting). No hay correo de contacto.

Cuenta qué has encontrado, cómo reproducirlo y en qué versión. Respondo de forma orientativa en unos 7 días;
es un proyecto personal, sin plazos garantizados.

## Antes de nada

La criptografía de NightFury OS (SHA-2, PBKDF2, AES, AES-GCM, ChaCha20-Poly1305, X25519, RSA, ECDSA y el TLS
de HTTPS) es una implementación propia **sin auditar**. No protejas con ella nada importante.

# Security policy

## Supported versions

Only the latest published version receives fixes.

## How to report a vulnerability

**Do not open a public issue.** Use GitHub's private report: the repository's **Security** tab →
**Report a vulnerability** (Private vulnerability reporting). There is no contact email.

Describe what you found, how to reproduce it and in which version. I aim to answer within about 7 days; this is
a personal project, so there are no guaranteed deadlines.

## First of all

NightFury OS's cryptography (SHA-2, PBKDF2, AES, AES-GCM, ChaCha20-Poly1305, X25519, RSA, ECDSA and the HTTPS
TLS) is a home-made implementation and has **not been audited**. Do not protect anything important with it.
